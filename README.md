# Heritage Building Maintenance Management System

## 📌 Overview
A relational database system designed to centralize and manage historic building inspections, restoration tasks, assigned specialists, and material costs. The project focuses on structured data management, reducing redundancy, and enforcing strict relational data integrity.

## 🛠️ Tech Stack & Concepts
* **Database:** SQL
* **Design & Modeling:** Entity-Relationship Diagram (ERD), Relational Schema Design, Normalization (3NF), Primary & Foreign Key Constraints

## 📂 Repository Structure
* `database.sql`: Contains the complete DDL/DML scripts for table creation, relationships, and sample data.
* `images/`: Contains the visual database models (ER Diagram and Relational Schema).
